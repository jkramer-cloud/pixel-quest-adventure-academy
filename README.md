# Pixel Quest — Adventure Academy

An original retro-inspired educational side-scrolling platformer prototype for the Naches Learning Hub. No Nintendo characters, music, or art are used.

## Version 0.1
- Four playable levels in World 1: Meadow Trail, Boulder Brook, Whispering Grove, and The Old Tower.
- Four cosmetic character choices: Scout, Nova, Gear, River.
- Responsive running and variable-height jumping, camera scrolling, collision detection, coyote time and jump buffering.
- Breakable bricks, mystery blocks, collectible coins, Growth Stars, Spin Orbs, checkpoints, and stage exits.
- Walkers, beetles and hopping creatures, defeated by stomping or a powered spin attack.
- Five-heart health system, healing shrines, educational reward blocks and knowledge gates.
- Grades 3–8 and selectable math, ELA, science, social studies, logic, with All Subjects selected by default.
- Local browser save for stage unlocks and settings.
- No libraries, servers or internet dependencies.

## Play
Use A/D or arrows to move; Space/W to jump; hold Shift to run; X to spin when charged; Esc to pause. On-screen controls are available on narrow screens.

## Deploy
Create a GitHub repository such as `pixel-quest-adventure-academy`, put `index.html` in its root, enable GitHub Pages at main / (root), and use its GitHub Pages URL in the Naches Learning Hub. No changes to the Hub have been made in this package.

## Known limitations and future development
This is an early, playable prototype rather than a completed 24-level game. The question library is intentionally small, and some educational questions only approximate grade targeting; content should be reviewed before use as formal assessment. Levels are procedurally assembled from curated patterns and need classroom balancing. Browser gameplay across devices has not been fully tested. The powered-up form is a simple larger sprite, not a detailed character animation sheet. Save data is local to a device/browser, and is not student-account synced. Future additions: more deeply authored maps, tile-art sprites, longer grade-specific question banks, enemy/boss variety, animations, and learning analytics.
